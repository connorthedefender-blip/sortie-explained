Sortie Explained Uploader

A private tool run by Connor Skluzacek for his own YouTube channel, Sortie Explained.

This app uploads and schedules Connor's own short videos on the Sortie Explained YouTube channel and reads that channel's analytics so he can see how the videos perform. It is not offered to the public and is used only by its owner.

It uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
